# PaperNX v0.10.0-comics.2 — rtk19 fork

Fixes large comic library covers and accelerates zoomed comic movement. The visible Fit page button resets zoom/pan and restores page curls; the + menu and right-stick click expose the same reset. Existing comic cover caches refresh automatically. Keep your books and reading data.

Install PaperNX.nro at sdmc:/switch/PaperNX/PaperNX.nro, or extract the Switch ZIP to the SD root. Back up books/ and data/ first. The fork uses upstream PaperNX's same application/data path.
