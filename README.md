תיקון לדפדופים רצופים בקומיקס, במיוחד במצב זוג עמודים ובקובצי CBR.

- מחוות ולחיצות נוספות נשמרות גם אם הזוג הבא עדיין לא נטען. הכנת התמונות והמידע לזיהוי זוגות מתבצעת ברקע.
- אפשר להתחיל לגרור את הזוג הבא מיד אחרי שחרור הדף הקודם.
- קורא ה־CBR נשאר פתוח לאורך הקריאה ושומר את מצב הפריסה, במקום להתחיל מחדש אחרי שלוש שניות ללא עבודה.
- הכנה מראש של עד שני זוגות קדימה, עם עדיפות לעמודים שביקשת לפתוח.
- תיקון שחרור מגע בסוויץ׳ ואיפוס אחיזת הדף באיבוד מיקוד.

הזום, אנימציות הדפדוף, הדפים הצמודים, הכיווניות, העדפות הקריאה, התפריטים ונתוני הספרייה נשמרו.
