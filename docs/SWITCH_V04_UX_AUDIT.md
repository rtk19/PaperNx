# PaperNX v0.4 physical Switch UX audit

The user supplied observations from ten v0.3 physical-device recordings. The video files are not available in this workspace, so this audit uses the supplied timestamps and descriptions; it does not claim a direct video inspection. All new v0.4 hardware retests are **UNVERIFIED**. Source changes and automated tests alone do not close a physical defect.
